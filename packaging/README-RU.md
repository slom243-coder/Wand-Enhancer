# WandEnhancer + Toolbox

Windows-патчер с дополнительной локальной панелью инструментов. Репозиторий и код не публикуются этим архивом.

## Установка

1. Полностью распакуйте RAR в отдельную папку.
2. Запустите `WandEnhancer.exe`, выберите установленный Wand и включите Remote Web Panel.
3. Примените патч и запустите Wand. Справа внизу появится кнопка **Toolbox**. Горячая клавиша по умолчанию: **Alt+Shift+E**.
4. Для удаления восстановите исходные файлы через Restore в патчере.

Toolbox и его страница встроены в Windows exe при сборке. Не нужно копировать исходники JavaScript вручную. Сборка не подписана цифровой подписью.

## Возможности

- Компактность, размер текста, контраст, снижение анимаций, скрытие боковой панели и рекламных карточек.
- Режимы трансляции и скриншота; личные блоки скрываются по настраиваемым CSS-селекторам. Перед трансляцией проверьте результат визуально: имена классов Wand могут измениться.
- Хоткей открытия панели; Alt+Shift+S — режим скриншота, Alt+Shift+F — фокус поиска Wand. Хоткеи работают в активном окне.
- Крупные элементы и управление D-pad/A внутри Toolbox.
- Заметки и справка, личная оценка совместимости, дата проверки и версия игры.
- Очередь прохождения с приоритетом и прогрессом, ссылки на гайды.
- Личные имена, пояснения, оценки и подтверждения отдельных функций в Toolbox.
- Поиск по схеме трейнера и заметкам, категории; восстановление фильтра и прокрутки по игре.
- Сравнение и применение пресетов из общего хранилища основной веб-панели.
- История последних 250 событий значений, экспорт истории, возврат исходных наблюдаемых значений текущего трейнера. Одноразовые действия исключены.
- Подтверждение остановки в Toolbox. Перехват штатной кнопки Wand — только если вы указали её точный CSS-селектор.
- Таймер сеанса, напоминание о перерыве, уведомления о состоянии игры/трейнера с разрешения браузера.
- Диагностика bridge, признаки устаревших данных, количество подключений, адреса для телефона.
- Экспорт/импорт заметок и настроек в JSON; резервная копия предыдущего сохранения и ручные копии.

## Режим просмотра

Флажок «Просмотр» блокирует команды только из Toolbox на этом устройстве.
`Start-ReadOnly.cmd` устанавливает `WAND_REMOTE_READ_ONLY=1` для запускаемого патчера и дочерних процессов. Закройте прежний Wand и запустите его через этот патчер. В таком запуске bridge блокирует **все** удалённые команды изменения значений, запуска и остановки независимо от интерфейса телефона. В диагностике должно быть «Режим bridge: Только просмотр». Чтобы вернуть управление, завершите процессы и запустите патчер обычным способом.

## Границы работы

- Скрипт внедрения идемпотентен, не сканирует DOM по таймеру и создаёт iframe панели только при открытии. При скрытии страницы сетевые запросы приостанавливаются. Это уменьшает работу самого расширения; потребление ресурсов основного Electron-клиента не измерено.
- История и события записываются только при открытой видимой панели. При закрытии соединение прекращается. При повторном соединении исходные значения фиксируются заново. Возврат значений не восстанавливает память игры или сохранения и не отменяет уже выполненные действия.
- Заметки, подписи и подтверждения реализованы в Toolbox, а не во всех штатных элементах Wand. Оформление штатного клиента зависит от совпадения селекторов с вашей версией.
- Настройки локальны для браузерного origin: смена адреса/порта означает другое хранилище. Разные устройства синхронизируются вручную через JSON.
- Режим для скриншотов скрывает панели интерфейса Wand и не меняет область окна самой игры.
- Ссылки поддерживают http/https. Автоматическое определение/открытие папок сохранений не реализовано.
- Существующий встроенный скрипт заменяет QR-код в Wand на адрес локальной панели. Новый набор не добавляет второй QR-рендерер.
- Автоматического кэширования загружаемых трейнеров, глобальных хоткеев вне активного окна, гарантированной поддержки неизвестных версий Wand и полного офлайн-запуска нет. Для анализа загрузок необходим исходный `resources/app.asar` конкретной версии.
- Реальная Windows-сборка и применение к Wand должны быть проверены на Windows. Прохождение web-тестов не заменяет этот этап.

## Сборка из исходников

Windows: Visual Studio 2022/MSBuild, targeting pack .NET Framework 4.8, Node 22 и pnpm 10.17.0.
Запустите `build.cmd`, затем `powershell.exe -NoProfile -File scripts/package-release.ps1` (нужен установленный WinRAR).
Готовый архив: `.out/WandEnhancer-Toolbox.rar`.
GitHub Actions `Build executable` выполняет эти шаги на Windows и сохраняет exe и RAR как приватные артефакты workflow.
